# Sample Data

This directory is reserved for sanitized sample data used for demonstration and testing of the ROAMER INDIA – STAFF & OPERATIONS MANAGEMENT SYSTEM.

## Purpose

Sample data can be used to demonstrate how the system works without exposing real company information.

## Privacy

Do not store real company or employee information in this directory.

Do not include:

- Real employee names
- Real phone numbers
- Real email addresses
- Real salary information
- Real bank details
- Real financial transactions
- Customer information
- Passwords or credentials
- API keys or authentication tokens
- Other confidential company information
